# disparo-whatsap

Projeto para envio de mensagens em massa via WhatsApp.

## Estrutura do Projeto

- `frontend/`: arquivos do site (HTML, CSS, JS)
- `backend/`: scripts de automação/API (opcional)
- `README.md`: instruções do projeto

## Como rodar localmente

1. Instale o Python (se ainda não tiver).
2. No terminal, navegue até a pasta do projeto e execute:

	cd frontend
	python -m http.server 8000

3. Abra o navegador e acesse: http://localhost:8000/index.html

Pronto! Você verá a tela de login.

---

Se quiser integrar backend futuramente, utilize a pasta `backend/`.
